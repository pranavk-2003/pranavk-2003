## About Me

I build robotics software with a focus on autonomous systems, navigation, perception, and real-world integration.

My work spans:

* **ROS 2 application development**
* **Autonomous navigation stacks**
* **SLAM and localization**
* **Sensor integration and data pipelines**
* **Embedded + robotics hardware workflows**
* **Simulation, debugging, and deployment**

I like systems that are not just clever in simulation, but reliable on hardware.

---

## What I Work On

* Navigation pipelines using **Nav2**, **TF2**, and **costmaps**
* Mapping and localization with **SLAM Toolbox**, **RTAB-Map**, and related tooling
* Robot software architecture with **rclcpp**, **rclpy**, services, actions, and lifecycle nodes
* Sensor fusion and perception using **OpenCV**, LiDAR, IMU, and camera stacks
* Embedded robotics integration with **Arduino**, **Raspberry Pi**, **Jetson**, and microcontrollers
* Simulation and development in **Gazebo**, **RViz**, and **Foxglove**
